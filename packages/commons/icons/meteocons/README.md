# Meteocons

Static "fill" weather icons from [Meteocons](https://meteocons.com/) by Bas Milius,
sourced from [basmilius/weather-icons](https://github.com/basmilius/weather-icons)
(`production/fill/svg-static`). Licensed under the MIT License.

Icons are mapped from WMO weather codes by `wmoWeather()` in
`packages/commons/src/weather.ts`. Add a new icon here (and to that map) if a code
needs a distinct glyph.
